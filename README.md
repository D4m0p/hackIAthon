# Agente de Bienestar Preventivo y Gamificación de Salud

Agente que analiza de forma anónima los diagnósticos más frecuentes del hospital,
diseña campañas de prevención y, cuando el asegurado cumple su chequeo, le otorga
puntos, nivel y descuento en la prima dentro del CRM en Notion.

## Equipo: empiecen aquí

**Lean [`CONTRATO.md`](CONTRATO.md) antes de hacer cualquier cosa.** Ahí está:

- **Sección 0:** regla obligatoria sobre commits y atribuciones. Aplica a todos.
- **Sección 1:** qué le toca a cada persona.
- **Sección 2:** pasos para crear el CRM en Notion (Persona 2).
- **Sección 3:** claves y secretos. Nunca se suben al repositorio (Persona 3: clave de Groq).
- **Secciones 4 a 7:** códigos de chequeo, formato de datos, reglas de puntos y privacidad.

> Este README se completará con la instalación y el enlace público cuando el agente esté desplegado.
